ASF Messenger (asli do-taraf chat)

CHALANE KA TARIKA
1) Node.js install hona chahiye (nodejs.org).
2) Is folder me terminal kholein:   npm install   phir   npm start
3) Browser me kholein: http://localhost:3000
   Dusre phone/PC se (same WiFi): http://<aapke-PC-ka-IP>:3000

ISTEMAL
- Har banda login kare, usko apna ASF number milta hai (Settings me dikhta hai).
- Dono ek dusre ka number "➕ Save number" se save karein. Number server par registered hona chahiye.
- Phir asli chat hoti hai. Koi auto-jawab nahi. Doosra offline ho to message baad me pahunchta hai.
- Test ke liye 2 alag browser/device use karein (ek hi browser me do account chats mix kar dega).
- Login demo me OTP: 123456.

ASF AI KEY (sirf ASF AI chat ke liye)
- App kholte hi ek popup aata hai, usme apni Gemini API key (AIza...) paste karke Save karein.
- Key sirf aapke browser me save hoti hai, code me nahi likhni.
- Baad me badalni ho: AI button > Settings > ASF AI key.

REAL GOOGLE LOGIN: login screen par "Set Google Client ID" dabayen.
